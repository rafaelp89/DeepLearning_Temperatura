### 📌 **Resumo do Arquivo "Oficina1.ipynb"**

#### **📚 Introdução**
Projeto apresenta a implementação de um modelo de previsão de temperaturas usando redes neurais LSTM (Long Short-Term Memory). O código está dividido em etapas claras, desde a importação de bibliotecas até a criação de dados fictícios e sua visualização. O objetivo principal é demonstrar como prever temperaturas diárias usando um modelo de aprendizado de máquina.

---

### **🔍 Principais Etapas do Código**

1. **📥 Importação de Bibliotecas**
   - Foram importadas bibliotecas essenciais para análise de dados e machine learning, como:
     - `numpy` e `pandas` para manipulação de dados.
     - `matplotlib` para visualização gráfica.
     - `MinMaxScaler` do `sklearn` para normalização dos dados.
     - `Sequential` e `LSTM` do `tensorflow.keras` para construção do modelo de rede neural.

2. **📊 Criação de Dados Fictícios**
   - Dados sintéticos de temperaturas diárias foram gerados para simular um período de 5 anos (365 dias/ano).
   - A temperatura foi modelada como uma função senoidal com ruído aleatório para simular variações naturais.
   - Os dados foram armazenados em um DataFrame do `pandas` e plotados em um gráfico para visualização.

3. **📈 Visualização dos Dados**
   - Um gráfico de linha foi criado usando `matplotlib` para mostrar a variação das temperaturas ao longo do tempo.
   - O eixo x representa as datas, e o eixo y mostra a temperatura em graus Celsius.

---

### **🎯 Conclusão Final**

O notebook apresenta uma estrutura bem organizada para a criação e visualização de dados temporais, com o objetivo de aplicar um modelo de previsão usando LSTM. Apesar de ainda não conter a implementação completa do modelo (como treinamento e avaliação), as etapas iniciais demonstram:
- ✅ Preparação dos dados sintéticos.
- ✅ Normalização e pré-processamento.
- ✅ Visualização clara das informações.
